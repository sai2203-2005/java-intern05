## 📌 Projects Included

### 1. Multiplication Table Generator (`MultiplicationTable.java`)
An interactive CLI Java application that generates multiplication tables based on user preference.

#### ✨ Features:
- **Single Number Table**: Generates a multiplication table for a specific number up to a custom limit.
- **Range of Numbers**: Generates multiplication tables for a range of starting and ending numbers up to a specified limit.
- **Interactive Console Menu**: Easy-to-use menu-driven interface with user input handling via `Scanner`.

---

## 🚀 How to Run

### Prerequisites
- [Java Development Kit (JDK 8+)](https://www.oracle.com/java/technologies/downloads/) installed.

### Steps to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sai2203-2005/java-intern05.git
   cd java-intern05
   ```

2. **Compile the Java program:**
   ```bash
   javac MultiplicationTable.java
   ```

3. **Run the application:**
   ```bash
   java MultiplicationTable
   ```
